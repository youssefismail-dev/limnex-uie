## 2. The slash fix (D1′)

### 2.1 The issue, documented

R-a, as registered for the decoder arms (`PREREG_E13.md` §3.2, carried into
`PREREG_E14.md` §3.2), counts a cell as a REGRESSION if:
- Δ > 0 at Holm p < 0.05 over all the cells of its mode; **or**
- its verdict worsens.

The second clause has now rejected three decoder rules, each at a Δ indistinguishable
from zero:

| experiment | arm | cell | verdict | Δ x | 95% interval | p | Holm p |
|---|---|---|---|---|---|---|---|
| E13 | D2 (`e12_dec`) | control benign P1Q1 PTH | UNDECIDED → CONVICTED | −0.0018 | [−0.0136, +0.0099] | 0.69 | 1.00 |
| E13 | D2 (`e12_dec`) | control benign P0Q1 QRY | UNDECIDED → CONVICTED | +0.0018 | [−0.0054, +0.0091] | 0.52 | 1.00 |
| E14 | D1′ (`e12_d1p`) | control benign P1Q1 PTH | UNDECIDED → CONVICTED | −0.0001 | [−0.0104, +0.0103] | 0.99 | 1.00 |
| E14 | combination (`e14_qd`) | free benign QRY | CLEARED → UNDECIDED | +0.0008 | [−0.0244, +0.0260] | 0.93 | 1.00 |

**Why a verdict can flip while x does not move.**
- A verdict compares (x − 0.05) / SE with 2.776.
- The SE comes from the spread across the five generations, and a decoder rule
  re-draws some of the strings.
  - For D1′'s cell: x 0.0576 → 0.0575, SE 0.0030 → 0.0027, t 2.53 → 2.78.
  - For the combination's cell: x 0.0309 → 0.0317, SE 0.0061 → 0.0067, t 3.13 → 2.73.
- The tell did not change. Only the estimate of its uncertainty did.
- A cell sitting near 2.776 can therefore flip on re-drawn strings alone.

**Why that is not the owner's "material regression".**
- The owner's decoder override asks that an intervention be rejected only for a
  "material regression elsewhere".
- A verdict flip with no measurable change in the cell is not a change in the cell.
  It is a change in a noise estimate.
- DC1, the registration these rules descend from (`PREREG_DC1.md`), counted only
  CLEARED → CONVICTED among verdict changes. E13 widened that to "any verdict
  worsens" without examining its false-alarm rate. That was my error in E13's
  registration, recorded at E13's read.

### 2.2 What stays exactly as it was

- **Clause (i) of R-a:** Δ > 0 at Holm p < 0.05 over the mode's cells.
- **Every other decoder criterion:** R-b to R-f, and K13-3 / K14-4.
- **The retrained-model rule:** K12c / G1, "a verdict worsens AND x rises by more
  than 0.0141". It already has a materiality margin and is untouched.
- **E3:** read on verdicts, unchanged. A verdict that flips on noise still counts
  against E3. The new rule decides only whether an intervention is *accepted*.

### 2.3 The new rule, registered here: R-a′

**Scope:** every comparison between two arms that share the same weights, i.e. a
decoder rule judged with DC1's paired rules. It replaces R-a there, from
2026-10-05.

**R-a′.** A gated cell (both classes, every computable cell, FULL included) is a
REGRESSION if either:
1. **(i), unchanged:** Δ > 0 with Holm-adjusted p < 0.05 over all the cells of its
   mode; or
2. **(ii):** its verdict worsens — any step down: CLEARED → UNDECIDED, UNDECIDED →
   CONVICTED, CLEARED → CONVICTED — **and** the cell itself rose measurably: Δ > 0
   with its own 95% interval wholly above 0 (lo > 0, the contrast DC1's rules
   compute, unadjusted).

**What the change does:**
- **It never relaxes the significance clause.** Any cell rising at Holm p < 0.05
  is still a regression.
- **A verdict change still counts whenever it comes with a real rise.** That
  includes CLEARED → UNDECIDED, which DC1's original rule ignored. So on verdicts
  R-a′ is stricter than DC1's rule.
- **A verdict change whose cell's interval contains 0 is recorded, but not
  counted.** This is amendment 1's principle (`PREREG_E13.md` §7), applied to
  cells: a change between two arms counts only if it is material *and* its
  interval excludes 0.

## 3. The query weight (Q): closed, rejected

- **`e14_q` and `e14_qd` are not adopted.** N2b, the query-content loss weight, is
  closed as rejected. There is no retry and no further weight tuning.
- **What E14 established, for the record** (`E14_RESULTS.md`):
  - more emphasis on query content improves query learning on the existing data:
    held-out query NLL falls by 0.07 (benign) and 0.18 (phishing) nats per
    character; free phishing QRY −0.031; benign P0Q1 QRY CLEARED;
  - **the cost is real at the model level, not only at the detector.** Every other
    content field's fit got worse, on validation and on training rows. As the noise
    reference, `e13_ctx` (e12_final's recipe changed only on phishing query rows,
    on the same batches) moved the benign fields by at most 0.002:

    | validation NLL, nats per character | e13_ctx − e12_final (noise reference) | e14_q − e12_final |
    |---|---|---|
    | benign LBL | +0.002 | **+0.038** |
    | benign PTH | +0.002 | **+0.028** |
    | benign QRY | +0.014 | **−0.086** |
    | phishing PTH | +0.012 | **+0.055** |
    | phishing SUB | +0.002 | **+0.041** |
    | phishing QRY | +0.024 | **−0.166** |

  - **[Reading, used in §4]** At the fixed budget (14.4M parameters, 20,000 steps),
    the model trades fit between fields. Giving queries more of the budget took fit
    from labels, paths, subdomains and fragments.
    - It is not a registered capacity reading. It does not unlock R3
      (`DECISION_2026-09-29.md` §4).
